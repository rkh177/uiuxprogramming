# 9주차 폼 UI와 입력 경험 설계

## 프로젝트 소개

- 사용자: 소스코드 유출 없이 사내 표준에 맞게 AI 코딩을 활용하려는 사내 개발자
- 목적: 사내 폐쇄망 기반 Qwen 로컬 LLM의 특징을 이해하고 AI 코드 리뷰를 요청한다.
- 핵심 행동: 서비스 소개를 확인하고, 데이터 수집에 동의한 뒤 AI 코드 리뷰 조건을 설정한다.
- 정보 순서: 서비스 소개 → 주요 기능 → 이용 방법 → AI 코드 리뷰 요청 설정 → 소식 받기

## 새로 추가한 기능

8주차 결과물의 AI 코드 리뷰 요청 폼에 **폼 UI 구조·입력 상태·검증과 피드백**을 보완했다. 파일명 필드에 글자 수 카운터와 조건 충족 상태를 추가했고, 중점 항목 체크박스 선택 여부에 따라 하위 입력이 활성화·비활성화된다. 최종 제출 시 저장 중 상태를 표시해 중복 제출을 방지하고, 저장 완료 후 결과 메시지를 보여 준다.

## 사용자 행동과 조건

| 항목 | 내용 |
|---|---|
| 진입 조건 | 데이터 수집에 동의하고 '서비스 시작하기' 클릭 후 리뷰 요청 흐름에 진입한 상태 |
| 사용자 행동 | 파일명 입력 → 리뷰 조건 선택 → 내용 확인 후 '설정 완료하기' 클릭 |
| 확인할 조건 | 파일명이 입력되었는지 |

### 성공 반응
- 버튼이 잠기고 "리뷰 요청을 저장하고 있습니다." 표시 후 완료 화면으로 이동

### 오류·미입력 분기 반응
- 파일명 빈 값으로 제출 시: "파일명을 입력해 주세요." 오류 표시, 1단계로 복귀 및 오류 입력칸으로 초점 이동
- 오류 수정 시: 오류 상태 즉시 해제

### 다음 행동
- '다시 설정하기'로 전체 입력과 화면 상태를 초기화하고 1단계로 복귀할 수 있다.

## 테스트 결과

1. 파일명 입력 중 글자 수 카운터 실시간 갱신 확인
2. 1자 이상 입력 시 테두리 초록색 + 조건 충족 안내 문구 표시 확인
3. "중점 항목 포함" 체크·해제 시 항목 수 영역과 라디오 버튼 활성화·비활성화 확인
4. 빈 값으로 제출 시 오류 메시지 표시, 1단계 복귀 및 오류 입력칸 초점 이동 확인
5. 오류 수정 시 오류 상태 즉시 해제 확인
6. '설정 완료하기' 클릭 시 버튼 잠김 + 저장 중 메시지 후 완료 화면 이동 확인
7. `index.html?save-error=1`로 저장 실패 시 메시지 표시, 입력값 유지 및 버튼 재활성화 확인
8. '다시 설정하기' 클릭 시 전체 입력 초기화 및 1단계 복귀 확인
9. 모바일(375px) 및 데스크톱(1280px)에서 폼 레이아웃과 버튼 조작 가능 확인
