# 10주차 내비게이션과 화면 이동

## 프로젝트 소개

- 사용자: 소스코드 유출 없이 사내 표준에 맞게 AI 코딩을 활용하려는 사내 개발자
- 목적: 사내 폐쇄망 기반 Qwen 로컬 LLM의 특징을 이해하고 AI 코드 리뷰를 요청한다.
- 핵심 행동: 서비스 소개를 확인하고, 데이터 수집에 동의한 뒤 AI 코드 리뷰 조건을 설정한다.
- 정보 순서: 서비스 소개 → 주요 기능 → 이용 방법 → AI 코드 리뷰 요청 설정 → 소식 받기

## 새로 추가한 기능

9주차 결과물에 **내비게이션 구조·현재 위치 표시·목록 필터·모바일 메뉴**를 추가했다. 상단 메뉴를 ul/li 구조로 개편하고 현재 주소에 맞는 메뉴 항목을 강조한다. 리뷰 이력 섹션을 신설해 완료·대기중 상태로 필터링할 수 있으며, 600px 이하 화면에서는 버튼으로 메뉴를 열고 닫을 수 있다.

## 사용자 행동과 조건

| 항목 | 내용 |
|---|---|
| 진입 조건 | 페이지를 열거나 주소 끝에 #이 붙은 상태 |
| 사용자 행동 | 메뉴 클릭으로 목적지 이동, 필터 버튼으로 리뷰 목록 범위 변경 |
| 모바일 추가 행동 | '메뉴 열기' 버튼 → 메뉴 선택 → 자동 닫힘 |

### 성공 반응
- 클릭한 메뉴만 강조되고 주소 끝 # 값이 함께 바뀐다
- 필터 선택 시 조건에 맞는 카드만 표시되고, 없으면 안내 문구가 나타난다

### 다음 행동
- 브라우저 뒤로 가기·앞으로 가기를 눌러도 현재 메뉴 강조가 함께 이동한다

## 테스트 결과

1. 메뉴 세 개가 각각 맞는 영역으로 이동하고 주소 끝 # 값이 맞는지 확인
2. 현재 메뉴 하나만 강조되고 브라우저 뒤로 가기·앞으로 가기에도 강조가 따라가는지 확인
3. 리뷰 이력에서 전체·대기중·완료 필터 선택 시 카드 수가 바뀌는지 확인
4. 완료 항목이 없는 상태를 필터하면 안내 문구가 나타나는지 확인
5. 600px 이하에서 '메뉴 열기' 버튼이 보이고 메뉴가 접히는지 확인
6. 버튼을 반복해서 누를 때 메뉴, 버튼 문구, aria-expanded가 함께 바뀌는지 확인
7. 모바일에서 메뉴 링크를 선택하면 목적지로 이동하고 메뉴가 닫히는지 확인
8. 9주차 입력 검증, 저장, 카드 조작 기능이 그대로 작동하는지 확인
9. 모바일(375px) 및 데스크톱(1280px)에서 메뉴와 필터 버튼 조작 가능 확인
