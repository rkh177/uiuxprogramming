# 7주차 사용자 흐름과 인터랙션

## 프로젝트 소개

- 사용자: 소스코드 유출 없이 사내 표준에 맞게 AI 코딩을 활용하려는 사내 개발자
- 목적: 사내 폐쇄망 기반 Qwen 로컬 LLM의 특징을 이해하고 AI 코드 리뷰를 요청한다.
- 핵심 행동: 서비스 소개를 확인하고, 데이터 수집에 동의한 뒤 AI 코드 리뷰 조건을 설정한다.
- 정보 순서: 서비스 소개 → 주요 기능 → 이용 방법 → AI 코드 리뷰 요청 설정 → 소식 받기

## 구현한 이벤트

1. click - 시작 버튼 클릭으로 리뷰 요청 다이얼로그 표시
2. click - 다이얼로그 동의/취소로 설정 플로우 진입 또는 해제
3. click - 다단계 플로우 이전/다음/완료/초기화 이동
4. input - 파일명 유효성 검사 (미입력 시 에러 메시지)
5. input - range 슬라이더 조작 시 커밋 범위 실시간 표시
6. change - 체크박스 상태에 따라 중점 항목 수 선택 영역 표시/숨김

## 화면 변화

1. 동의 체크 시 시작 버튼 활성화, 미체크 시 비활성화
2. 시작 버튼 클릭 시 다이얼로그 표시, 취소 시 체크박스 해제 및 플로우 숨김
3. 파일명 미입력 시 has-error 클래스 및 에러 메시지 표시
4. range 조작 시 "n커밋" 실시간 반영, 체크박스 상태에 따라 항목 수 fieldset 표시/숨김
5. 3단계에서 파일명/커밋 범위/중점 항목 요약 표시, 완료 후 초기화 가능

## 테스트 결과

1. 파일명 미입력 시 에러 메시지 표시 및 포커스 이동 확인
2. 파일명 입력 후 다음 클릭 시 2단계로 정상 이동 확인
3. range 슬라이더 조작 시 1커밋/3커밋/5커밋 값 정확히 표시 확인
4. 중점 항목 체크/해제 시 항목 수 선택 영역 표시/숨김 확인
5. 요약 화면에 입력값 정상 표시 확인
6. 요약 화면 수정하기 클릭 시 2단계(조건 선택)로 복귀 확인
7. 다시 설정하기 클릭 시 전체 초기화 및 1단계 복귀 확인
