# 8주차 새 기능 추가와 상태·피드백 처리

## 프로젝트 소개

- 사용자: 소스코드 유출 없이 사내 표준에 맞게 AI 코딩을 활용하려는 사내 개발자
- 목적: 사내 폐쇄망 기반 Qwen 로컬 LLM의 특징을 이해하고 AI 코드 리뷰를 요청한다.
- 핵심 행동: 서비스 소개를 확인하고, 데이터 수집에 동의한 뒤 AI 코드 리뷰 조건을 설정한다.
- 정보 순서: 서비스 소개 → 주요 기능 → 이용 방법 → AI 코드 리뷰 요청 설정 → 소식 받기

## 새로 추가한 기능

7주차 결과물의 AI 코드 리뷰 요청 완료 화면에 **리뷰 평가 기능**을 추가했다. 사용자는 코드 리뷰 설정 완료 후 별점(1~5점)과 한 줄 코멘트를 남길 수 있으며, 등록한 평가는 완료 화면에 바로 표시되고 이후 수정도 가능하다.

## 사용자 행동과 조건

| 항목 | 내용 |
|---|---|
| 진입 조건 | AI 코드 리뷰 요청 4단계(완료 화면)에 도달한 상태 |
| 사용자 행동 | '리뷰 평가하기' 버튼 클릭 → 다이얼로그에서 별점 선택 → 평가 내용 입력 → '평가 등록하기' 클릭 |
| 확인할 조건 | 별점이 선택되었는지, 평가 내용(텍스트)이 입력되었는지 |

### 성공 반응
- 다이얼로그가 닫히고, 완료 화면에 등록된 별점(★☆ 조합)과 코멘트가 즉시 표시된다.
- '평가 수정하기' 버튼이 나타나 재등록이 가능한 상태가 된다.

### 오류·미입력 분기 반응
- 별점을 선택하지 않고 '평가 등록하기' 클릭 시: "별점을 선택해 주세요." 오류 메시지 표시, 다이얼로그 유지
- 평가 내용을 입력하지 않고 '평가 등록하기' 클릭 시: "평가 내용을 입력해 주세요." 오류 메시지 표시 및 텍스트 영역으로 포커스 이동

### 취소 분기 반응
- '취소' 버튼 클릭 시: 다이얼로그가 닫히고 완료 화면으로 복귀하며 별점·코멘트 입력 내용은 유지되지 않는다.

### 다음 행동
- 평가 등록 후 '다시 설정하기'로 전체 흐름을 초기화하거나, '평가 수정하기'로 평가를 다시 등록할 수 있다.

## 테스트 결과

### 정상 경로
1. 코드 리뷰 요청 완료 화면에서 '리뷰 평가하기' 버튼 클릭 시 다이얼로그 표시 확인
2. 별점 3개 선택 후 코멘트 입력 → '평가 등록하기' 클릭 시 다이얼로그 닫힘 및 완료 화면에 "★★★☆☆"와 코멘트 표시 확인
3. '평가 수정하기' 클릭 시 다이얼로그 재오픈, 기존 별점 상태로 표시 확인
4. 별점 변경 후 재등록 시 완료 화면 내용이 새 값으로 갱신됨 확인

### 오류 경로
5. 별점 미선택 상태에서 '평가 등록하기' 클릭 시 "별점을 선택해 주세요." 메시지 표시 및 다이얼로그 유지 확인
6. 별점 선택 후 코멘트 미입력 상태에서 '평가 등록하기' 클릭 시 "평가 내용을 입력해 주세요." 메시지 표시 및 텍스트 영역 포커스 이동 확인

### 취소 경로
7. 다이얼로그에서 '취소' 클릭 시 다이얼로그 닫힘 및 완료 화면 복귀 확인
8. 별점 선택 후 취소 시 완료 화면에 평가 결과가 표시되지 않음 확인 (미등록 상태 유지)

### 기존 기능 회귀
9. '다시 설정하기' 클릭 시 전체 입력 초기화 및 1단계로 복귀 확인
10. 모바일(375px) 및 데스크톱(1280px) 뷰포트에서 다이얼로그 레이아웃과 버튼 조작 가능 확인
